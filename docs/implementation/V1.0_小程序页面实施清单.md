# 6. V1.0 明确不开发

- 社区活动；
- 团购/拼团/社区集采；
- 报事报修/物业工单/巡检；
- 空间预约；
- 运营作业小程序；
- 积分商城/签到/会员等级；
- 骑手调度；
- 复杂仓储；
- 个人在线收款和资金托管；
- 停车设备、闸机、车牌识别、实时车位；
- AI 语义识别、知识图谱等课题创新点正式功能。

# 7. 实施更新原则

当 03 / P3 / P4 / P5 详细设计完成：

1. 不改一级 IA；
2. 在本清单中将对应 `TBD-*` 页面冻结为正式页面；
3. 建立与 Stitch 母版的映射；
4. 必要时只新增“新页面类型”视觉母版；
5. 更新 Codex Prompt，不重新定义整个 Design System。
