# 大光路智慧社区小程序

Vue 3 + uni-app 工作区，包含两个独立构建、独立发布的微信小程序：住户端与商户端。当前全部展示数据均为 Mock，未接入真实登录、业务 API、权限、支付或微信发布。P0 后续接口复用方向已调整为 LiLiShop，历史阶段 01–04 文档保留原有技术背景。

## P0 第一批｜住户商城发现链路（2026-10-04）

- 首页、商城首页、商品列表与商品详情按大光路单社区展示；四页无需 Project 选择或切换。
- 首页推荐与商城、详情使用同一商品数据来源，商品身份、名称、商户和价格保持一致；首页保留对应的既有生活摄影素材。
- 商城搜索进入统一商品列表，使用 `keyword/categoryId/sort`，支持商品/商户/店铺关键词、启用分类、销量与价格双向排序及空结果恢复；商品卡补齐店铺名、卖点和销量，详情补销量/评价摘要。
- 多规格商品卡加号先进入详情；详情通过底部弹层选择完整规格组合和数量，联动价格、库存与图片，未选齐/库存不足/店铺不可交易时阻止提交。详情只展示履约说明，在确认订单页选择履约方式；购买数量完整传递到购物车和确认页金额。
- 首页推荐排除无可售 SKU 和不可交易商品；商城列表保留售罄展示。核查发现的六项已补齐，并新增 `node scripts/check-p0-discovery.mjs` 验证查询、资格、库存、数量及页面提交守卫。
- 本轮通过双端 type-check、双端 mp-weixin 构建、住户 H5 构建、边界/视觉静态检查及实际 H5 点击走查；微信开发者工具/真机、真实 LiLiShop 接口仍待后续验证。

范围、文件和验证明细见 `docs/codex/P0_01_住户商城发现链路_实施结果.md`。方案全文已保存为 `docs/requirements/大光路智慧社区_P0商城闭环_前端原型修改方案_V1.0.md`；当前完成口径为第一批前端 Mock 原型，后续批次仍需按新版方案改造。

## 结构

```text
apps/resident-miniapp/   # 首页｜服务｜商城｜我的
apps/merchant-miniapp/   # 工作台｜经营｜订单｜我的
packages/theme/          # 唯一 Design Token 与全局样式
packages/ui/             # 唯一公共组件与 SVG 图标
packages/common/         # 类型、Project 上下文工厂、工具、加载状态
packages/business-common/# 端级 Mock 适配器
```

两个 App 都通过本地链接引用 `packages` 的同一份源码；不以登录角色决定一级导航。住户首页摄影 Mock 仅在住户端静态资源中，商户端不会打包。

## 命令

```powershell
npm.cmd install --cache .npm-cache
npm.cmd run dev:resident:mp-weixin
npm.cmd run dev:merchant:mp-weixin
npm.cmd run build:resident:mp-weixin
npm.cmd run build:merchant:mp-weixin
npm.cmd run type-check
npm.cmd run check:boundaries
```

产物分别位于 `apps/resident-miniapp/dist/build/mp-weixin` 和 `apps/merchant-miniapp/dist/build/mp-weixin`。两份 `src/manifest.json` 的微信 AppID 仍为空，项目方配置后才能导入对应微信主体发布。
